How it works

Using the prediction interface

01
Select a stock
Choose any of the 10 tracked tickers from the dropdown — AAPL, MSFT, GOOGL, AMZN, NVDA, META, TSLA, AVGO, ORCL, or AMD.
02
Auto-trigger inference
The system automatically calls the FastAPI backend, which runs the stock's sector-specific XGBoost model on the latest normalised technical and fundamental features.
03
View results
The prediction card shows the Buy / Hold / Sell recommendation, the model's calibrated confidence score, and whether the sector is currently rated Normal Confidence or Watch.
