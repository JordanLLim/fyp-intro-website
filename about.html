About the Project

Webservice for Stock Market Prediction

An AI-driven financial intelligence platform that transforms complex market data and news sentiment into clear, actionable investment insights for everyone from beginner investors to seasoned traders.

Background

Problem & Approach

The Problem

Individual investors face information overload, such as countless real-time news, price data, and technical signals that are difficult to interpret without professional knowledge.

Most existing platforms focus on powerful analytics but sacrifice usability, leaving beginner investors overwhelmed. Others lack sentiment analysis, missing the "why" behind price movements.

Our Approach

A full-stack web platform combining XGBoost + FinBERT AI predictions with real-time dashboards, simulated portfolios, expert portfolios, and a community forum.

The platform supports five user roles which are Basic User, Premium User, Consultant, Administrator, and Guest. Our approach ensures each user type has tailored access to features matching their needs.

Vision

Our vision

We are dedicated to transforming how individuals understand and interact with financial markets. Our vision is a platform where data-driven insights are at the core of every investment decision, accessible to anyone with an internet connection, not just professionals.

For Beginner Investors

Predict trends with sentiment intelligence, monitor markets in real-time, simplify complex patterns through interactive dashboards, and learn through a Knowledge Hub and expert portfolios.

For All Users

Empower smarter investing with real-time news insights, enhance analysis with interactive charts, and improve trading decisions through direct interaction with certified stock consultants.

Architecture

System architecture

Three-tier architecture connecting a React.js frontend, FastAPI backend, and MySQL database, with an external stock API integration and ML prediction engine.

Layer Description
Presentation Layer React.js frontend where users search stocks, view dashboards, manage watchlists, check predictions, and access account features via an interactive web interface.
Application Layer FastAPI backend that handles user authentication, role-based access, stock data processing, AI prediction requests, portfolio functions, and all system logic.
Data Layer MySQL database that stores user accounts, roles, watchlists, portfolio records, transaction history, prediction results, alerts, forum posts, and expert content.
AI Pipeline

Machine learning pipeline

Eleven independent XGBoost classifiers, one per S&P 500 GICS sector, trained on technical, macroeconomic, and fundamental data to classify every stock as Buy, Hold, or Sell.

Data retrieval & feature engineering
Daily OHLCV price data, technical indicators (RSI, MACD, Bollinger Bands, ATR), macroeconomic signals (10-year Treasury yield, S&P 500 momentum/RSI), and company fundamentals (P/E, P/B, ROE, ROA, revenue growth, dividend yield) are combined into 58 features per stock.

Per-sector XGBoost training
Eleven independent XGBoost classifiers, one for each GICS sector, are trained to reflect how the relationship between features and future returns differs between industries. Each model outputs a Buy, Hold, or Sell classification.

03
Probability calibration
Each sector model's output probabilities are passed through isotonic calibration on held-out data, so a predicted confidence score more reliably reflects the true likelihood of that outcome.
Isotonic calibrationHeld-out validation
04
Confidence-gated prediction
Each sector's stored validation AUC and precision are checked against a reliability threshold. Sectors that meet it (e.g. Utilities, Energy, Real Estate) show normal-confidence Buy/Hold/Sell calls, while sectors below it are downgraded to a lower-confidence Watch label.
